# 0.1.12：子代理工具卡片与导航复核

日期：2026-10-21。仅修改本地插件；未连接用户服务器、安装远程扩展或推送代码。

## 问题与改动

原实现把子代理调用当作通用工具输出。传到 Webview 的精简卡片只保留类型和标题，
没有保留子代理引用，因此卡片本身不能进入子会话；底部 Tasks 行仅打开旁侧详情。
父会话目录已登记、但尚无会话摘要的子代理，以及摘要被标为空的子代理，也可能缺少入口。

现在从官方调用结果重建有数量限制的精确 ID 引用，保留至精简传输与历史恢复。
支持标准委派、send_message、interrupt_agent，以及 run_code 的标准启动输出和结构化
activation 结果。不会把描述文字当作 ID，也不执行插件 presenter。

- 点击卡片中的子代理名称进入子会话；右侧箭头打开独立详情。
- 使用父目录校验关系；必要时通过只读 `session/projections` 获取单个目录。
  目录引用可在没有列表摘要时保留，并以准确的父子地址打开，不创建新的 DSH 会话。
- 原始参数与结果在 Details 中折叠查看，分页仍有大小限制。进入子会话不要求加载原始输出。
- 状态取自子代理自身，不把“委派调用已完成”当作“子代理已完成”。
- 失败显示具体原因，45 秒超时后允许手动重试，不自动重发。旧项目、旧运行时及不相关
  会话的请求被拒绝。外部执行保持官方的信息项语义，不作为本地会话打开。
- 底部 Tasks 和子代理详情中的嵌套工具卡片采用相同的主入口与旁侧入口。

## 布局依据

以本机官方 `@deepseek-ai/dsh-client-ui-subagent@0.2.1-rc.2` 的目录行为为依据：固定的
14px 状态列；名称、模式和活动信息形成主次层级；右侧分两行显示用量与耗时；独立的
旁侧打开按钮。本地卡片名称为 12px，辅助状态与折叠入口为 11px，用量列为 10px。
使用 VS Code 主题颜色和 DSH 半径变量，不增加大图标、阴影或默认展开的参数区域。
多引用列表限制高度，避免大量子代理占满对话页。
