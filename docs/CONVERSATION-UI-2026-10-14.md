# 会话目录与文件变更摘要：0.1.4

后续代码与安全复核发现并修正了跨会话差异操作和草稿覆盖问题，修正版为 0.1.5，见 [发布前复核记录](RELEASE-REVIEW-2026-10-15.md)。本页保留 0.1.4 的实现与初次验证记录。

本轮参照 [Codex 官方 IDE 说明](https://learn.chatgpt.com/docs/codex/ide)，并检查官方扩展 `openai.chatgpt` 的可获取发行版 `26.51007.21434`。静态资源中的最近会话搜索、View all 入口、新会话输入区和操作菜单用于核对交互结构；未安装参考扩展或访问用户真实会话。

## 会话导航

- 左上角返回按钮及顶部列表的 View all 入口打开完整会话目录。主页可直接输入并选择新会话模型；顶部列表保留最多 12 个最近主会话，搜索和完整目录提供其余会话入口。
- 主页草稿与当前会话草稿分离，并按项目保存于当前 Webview 的内存。浏览目录不创建会话；提交、添加附件或拖放文件时才创建新会话。文本发送等待对应的新会话状态和创建回执。
- 最近、归档、标题搜索和正文搜索均排除子代理。完整子代理数据保留在宿主模型中，供 Tasks 和独立详情面板使用。子代理的待审批、待回答和运行状态汇总至主会话指示器。
- 会话行采用单行标题、时间和悬停／键盘焦点可见的操作按钮。操作通过独立浮动菜单执行，支持 Rename、Archive 或 Restore。归档提供原生 Undo 通知；重命名使用 VS Code 输入框。归档不是删除会话数据。
- 方向键可从搜索框进入列表；右方向键打开操作菜单。Escape 先关闭操作菜单，再关闭快速列表。返回目录后，当前会话的阅读位置和草稿保留。

创建请求使用每个 Webview 独立的随机标识，并检查项目、原会话及加载代次。过期创建回执不会触发发送。主页拖放和粘贴先建立新会话，再使用现有附件流程；项目文件引用添加完成前，发送等待回执。编辑器候选文件仍不自动添加。

## 文件变更摘要

- 默认折叠显示去重文件数、增删行数、Review 和操作入口。展开后显示紧凑文件行，点击文件名打开对应差异。
- 保留各回合的独立差异、Keep 和 Revert。重复修改同一文件时，操作仍携带对应回合，避免操作错误快照。
- 单文件和全部修改的回退能力仍由完整快照决定。没有完整快照时禁用 Revert；原有未保存编辑保护保留。
- 展开状态按会话保存；会话切换或快照更新关闭过期菜单。控件的字号与行高独立于聊天正文字号。

## 验证

`npm run check`：92 个测试文件通过，1158 项测试通过、1 项平台测试跳过；类型检查与生产构建通过。新增行为测试覆盖会话过滤、归档身份、主页发送顺序、过期回执、创建期间导航、模型选择、项目草稿、文件拖放／粘贴及各回合差异操作。

真实 Chromium：20 组检查通过，未检测到未捕获异常。会话主页覆盖深色、浅色、高对比度及 320×400、420×800、650×800，共 9 个组合；保留原有聊天和任务面板回归。18px 聊天字体下，折叠变更摘要高度不超过 40px，文件行高度不超过 34px；操作菜单和主要控件位于窗口内。

VSIX 为 `artifacts/dsh-sidebar-0.1.4.vsix`，37 个文件，30 个生产资产与当前构建逐项一致。说明、版本与发布内容已核对；源码、测试、参考扩展资源、日志和临时数据不进入安装包。

日志、安装包检查结果和预览位于忽略目录 `artifacts/ui-review/session-014/`。截图使用生产 Webview 代码与示例状态渲染，不是用户真实会话。本轮验证没有发起模型请求，也没有替换本机或远端已安装扩展；真实 VS Code 及 Remote SSH 安装后的交互仍需验收。
