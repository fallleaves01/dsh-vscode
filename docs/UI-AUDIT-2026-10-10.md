  输入框固定在底部，展示 Queue／Steer 和发送快捷键说明。

## 本轮确认并修复的缺陷

| 缺陷 | 成因、影响和修复 |
|---|---|
| 指定 DSH 完整路径仍可能因旧 PATH 启动失败 | 官方 npm 安装的 POSIX `dsh` 是带 `/usr/bin/env node` 的 JS 入口；完整 DSH 路径不保证 PATH 里有 Node。现在校验官方包及 bin 入口，直接用相邻 Node 执行；没有相邻 Node 时使用扩展主机的 Node，并补齐该 Node 目录到子进程 PATH。自定义包装脚本和裸命令保持原有语义。 |
| 停止的子任务可能显示 NaN 耗时 | 有 `activeSince`、没有 `activeThrough`，且任务已经停止时，旧计算把未定义的终点参与减法。现在只有有限的终点才累计活动时长，否则保留已记录耗时。 |
| 第一层子任务与嵌套任务缩进不正确 | 父层级 `-1` 经逻辑默认值运算变成 `0`，把直接子任务多缩进一层。现在明确区分直接子任务和后代层级。 |
| 详情面板卸载后遗留操作监听器 | 旧卸载仅移除接收和表单监听，返回、停止、刷新、历史及动态按钮仍可发消息。现在通过监听器生命周期统一释放，卸载后旧控件不再发送操作。 |
| 无对应请求的正文响应可能抛异常 | 找不到正文缓存时，可选访问结果与缺失 requestId 都是 undefined，旧条件误判匹配并访问不存在的缓存。现在要求缓存存在且字符串 requestId 匹配待处理请求。 |

启动修复用本机实际官方 DSH 验证过：在 PATH 为 `/usr/bin:/bin` 的环境中，
解析到 `/opt/homebrew/bin/node`，`--version` 正常退出并返回 `0.2.0-rc.2`。
这项修复需要安装新版插件才会生效，并不修改 VS Code Server 自身缓存的环境。

## 安装与验收边界

安装包：[dsh-sidebar-0.1.0-ui-refresh.vsix](../artifacts/dsh-sidebar-0.1.0-ui-refresh.vsix)。

本轮没有覆盖远端已安装扩展、修改集群配置、升级 DSH 或发布 Marketplace。
