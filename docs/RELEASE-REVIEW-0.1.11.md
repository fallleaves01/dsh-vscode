# 0.1.11：多窗口共享运行时复核

日期：2026-10-20。范围：本地插件源码、隔离运行时、浏览器检查及 VSIX；未连接用户服务器，
未安装扩展、发布版本或推送代码。

## 成因与修复

此前的登记文件使用原子替换，但“查找实例—启动—登记”没有跨进程互斥；两个窗口可以
同时判定没有实例。历史搜索和 Schedule 通过启动扩展配置启用，旧实现会因此跳过复用。
插件版本号差异、连接失败后的自动回退，以及登记与连接记录的异步写入，也可能产生
竞争实例。首次启动窗口持有输出管道，进程句柄本身不足以保证其退出后的共享生命周期。

0.1.11 将启动、连接登记和最后使用者退出纳入同一互斥协议。协议使用每个参与者独立的
进程身份与顺序记录，不按时间直接撤销存活参与者。Linux 进程身份使用系统启动标识和
进程启动时钟计数；旧时间戳格式视为身份不确定，不据此误判进程已退出。

实例登记按主机、OS 账号及 DSH home 组织，不依赖 VS Code 配置目录。已知旧登记目录
通过私有指针保留原连接记录，避免将旧实例和新使用者分成两套账目。配置兼容性比较
启动参数、DSH 版本、托管协议和启动环境摘要；插件 UI 版本单独变化不阻止共享。
历史搜索和 Schedule 使用私有、不可变且按内容命名的配置文件，不再跳过复用。

存活实例连接失败、身份不明确或配置不兼容时，保留记录并显示错误，不自动启动第二个
写入进程。启动辅助程序异常退出后，如果仍不能排除 DSH 子进程存活，也保留启动记录。
其他窗口使用期间拒绝重启和终止遗留进程。重启的会话控制器入口在断开当前连接前检查
共享状态，并在实际停止时再次检查。

## 生命周期

- 首次启动窗口退出：辅助程序继续读取 DSH 输出，其他窗口继续使用同一实例。
- 最后一个窗口正常退出：停止 DSH，清除实例记录，辅助程序随子进程结束而退出。
- 所有扩展主机异常退出：辅助程序根据 PID 和启动身份检查连接记录；确认没有存活使用者
  后采用 30 秒宽限期，每 5 秒检查一次，随后停止 DSH。检查或身份判断失败时不冒险终止。
- SSH 暂时断线：如果远程扩展主机仍存活，则连接记录有效，DSH 保留；恢复后可重新连接。
- DSH 已清理：下次启动建立新实例；磁盘上已保存的会话历史仍保留。

辅助程序没有自动重启循环，不保存输出日志。IPC 诊断队列有容量上限；断开首次启动
窗口后继续读取并丢弃输出。窗口绑定的原生调试桥接不参与共享，需要关闭自主调试。

首次升级需先完成任务，在所有使用窗口更新到 0.1.11，关闭并重新加载以替换旧运行时。
旧扩展主机不实现新互斥协议；无托管协议的旧实例不会被当作稳定共享实例直接接入。
不会扫描全机进程、强制接管外部 DSH 或删除会话锁文件来绕过写入互斥。

## 验证

完整检查包含 TypeScript 类型检查、全部 Vitest 测试及生产构建。另使用临时 HOME、DSH_HOME
和配置目录执行官方 DSH 0.2.1-rc.2 的真实多进程检查：同时启动只有一个服务进程；两个
客户端访问同一会话；不同项目保留目录；历史搜索与 Schedule 可用；关闭首次启动窗口、
另一窗口崩溃、重新连接及最后退出均符合上述行为。启动中首次扩展主机崩溃后可由新窗口
接入；所有扩展主机被终止后，DSH 和辅助程序均退出。没有发送模型推理请求。

最终完整检查为 104 个测试文件通过，1,360 项测试通过、1 项跳过。Chromium 聊天检查
25 组、设置检查 8 组通过。最终构建的辅助程序再次通过真实多进程检查。

另通过 Chromium 聊天与设置检查，以及官方设置读写、配置修订冲突、提供商凭据操作、
历史、子代理观察、上传、重命名和归档检查。真实多进程测试运行于本机 macOS；Linux
身份逻辑通过注入的 /proc 样例验证。没有在用户的两窗口 Remote SSH 环境中执行验收。

可复现命令：`npm run check`、`npm run test:shared-runtime`、`npm run test:scroll-browser`、
`npm run test:settings-browser`、`npm run test:settings-runtime`、`npm run test:task-runtime`。
结果、截图、依赖审计及打包检查保存在本地忽略目录 `artifacts/ui-review/shared-runtime-fix/`。

## 隐私与依赖

实例启动 URL 包含认证令牌，保存在 POSIX `0600` 文件中，目录权限为 `0700`；不会写入
日志、Webview 状态或同步设置。启动环境凭据只参与本地随机密钥的 HMAC 计算，不将其
原值写入配置指纹。辅助程序通过 IPC 接收启动环境，不将凭据加入其命令行或输出文件。
拒绝链接形式或权限不安全的登记目录；不能证明所有使用者退出时不执行自动终止。

扫描覆盖可提交文件、暂存内容和未推送提交。命中均为测试中的合成令牌、PEM 标记、
示例路径或示例 URL 密码；未发现实际密钥、用户会话或服务器内容。最终 VSIX 已核对
版本、构建产物字节和文件清单，不含源码、测试、审计材料、凭据、历史及 source map。
扫描覆盖 260 个可提交文件；19 个命中均为合成测试样例。VSIX 共 39 项，大小为
811,404 字节，29 个构建资源与本地构建字节一致。SHA-256 为
`0fbfff2137649d287a5a770b4cd6d4d9c2bcb0d8c3afce519bfb9880f6fcd7c2`。

公共依赖审计仍报告 `braces@3.0.3` 的既有高危递归深度问题。现有 128 层限制补丁及七项
回归测试通过。构建输入清单确认该包未进入扩展与辅助程序的运行时 bundle。审计不能描述为零告警，
本次检查也不构成不存在其他缺陷或隐私风险的证明。
