# 0.1.4 复核与 0.1.5 修正

复核日期：2026-10-15。检查范围为尚未推送的会话主页、顶部会话列表、归档管理、文件变更摘要及关联代码。发现的问题修正后发布为 **0.1.5**，区别于此前交付的本地 0.1.4 安装包。

## 发现与修正

| 问题 | 触发与后果 | 修正 |
|---|---|---|
| 差异操作消息缺少来源会话 | 另一视图已切换会话，但旧 Webview 尚未刷新；旧消息可能操作当前会话中同路径、同回合的快照 | 消息携带会话和项目；宿主拒绝来源不匹配的 Review、Keep 和 Revert；延迟工具差异保留原视图的来源 |
| 回退确认后重新读取当前会话 | 等待确认时会话发生变化，原实现可能回退新会话的文件 | 捕获会话、项目和加载代次，确认后再次校验；目标改变时不执行回退 |
| 创建回执覆盖后续草稿 | 编辑器引用使新会话输入区提前可见，用户已输入后续文本，创建回执随后到达 | 成功发送主页文本后保留后续草稿；暂时无法发送时保留两段文本 |
| Enter 未等待发送回执 | 按钮已禁用，但 Enter 仍可重复提交尚未消费的附件 | Enter 与按钮使用相同的 pending-send 门控，回执到达后才允许下一次提交 |

来源消息、两种草稿覆盖场景以及单文件／全部回退确认场景共 5 项回归在修正前失败，修正后通过。新增用例检查宿主拒绝过期或不完整消息，并验证目标未变化时仍可正常回退。创建流程直接使用返回的真实会话 ID，并在选择模型前校验目标。
