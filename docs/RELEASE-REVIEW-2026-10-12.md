# 0.1.2 发布前复核与 0.1.3 修正

复核日期：2026-10-12。范围包含本目录尚未推送的 runtime、任务详情、UI 和主动文件上下文改动，以及已有的未推送提交。发现的问题修正后将版本升为 **0.1.3**，以区别于此前交付的本地 0.1.2 VSIX。

## 发现并修复的问题

| 问题 | 触发与影响 | 修正 |
|---|---|---|
| 排队斜杠命令丢失图片 | 对话运行中提交带图片的命令，输入框已接受发送，但队列只保留文字 | 队列保存图片，自动和手动执行均传回原附件 |
| 重复空闲事件并发执行命令 | 前一条命令尚未完成又收到空闲通知，可能提前执行下一条 | 单个串行 drain，逐项检查运行状态、连接、占用和 runtime 队列 |
| 会话队列显示串到另一会话 | 切换会话后删除旧会话排队项，旧队列覆盖当前列表 | 只向当前会话发布对应队列；断线手动执行不提前删除排队项 |
| 命令参数进入日志 | 排队和执行日志记录整条命令，参数可能包含私人文本 | 生命周期日志仅记录命令名称 |
| 凭据脱敏覆盖不足 | API Key、refresh token、命令行参数及无标签回显可能进入输出；启动异常还会进入状态与调用方 | 扩充字段和参数脱敏；登记 SecretStorage 和继承环境中的 DeepSeek Key；启动错误的 message/stack 同样脱敏 |

队列的图片、日志、串行执行和会话隔离回归先在原实现上复现失败，修正后通过。环境变量凭据的无标签回显也先复现再修正。没有为失败命令增加自动重试。

## 依赖安全

审计初始报告包含 39 条告警（1 critical、13 high、20 moderate、5 low）。更新 MCP SDK 至 1.31.0、DOMPurify、Vitest、WebSocket 及兼容的传递依赖后，原始 `pnpm audit --json` 仍有 **1 条 high**：打包工具链中的 `braces@3.0.3`，不能表述为零告警。

- MCP SDK 的 [GHSA-6qxp-vccf-f47h](https://github.com/modelcontextprotocol/typescript-sdk/security/advisories/GHSA-6qxp-vccf-f47h) 针对 OAuth 客户端；插件使用 MCP server 接口，并已升级到公告的修复版本。
- `braces` 的 [GHSA-vfj7-8cjw-p6xm / CVE-2026-93687](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) 是深层 AST 递归造成栈溢出的可用性问题。复核时尚无已发布的上游修复版本。已添加 [本地补丁](../patches/braces@3.0.3.patch)，在 parse 和 compile/expand/stringify 的递归路径限制深度；锁文件和 pnpm 配置引用补丁，冻结安装通过。
- 7 项 [补丁回归](../tests/build-dependencies.spec.ts) 检查深层括号字符串、调用方直接提供的深层 AST，以及正常项目 glob 的输出。防护范围是该公告所述的递归栈耗尽；版本号仍为 3.0.3，审计工具因此继续报警。`braces` 来自 VSCE 的 secretlint/glob 链，不进入 VSIX；补丁文件也排除在 VSIX 外。上游发布修复后应替换本地补丁。
- KaTeX 固定为已验证的 0.18.7；VS Code 类型固定为最低支持的 1.100.0。未通过忽略公告或关闭凭据扫描使审计变绿。

## 发布内容与隐私
